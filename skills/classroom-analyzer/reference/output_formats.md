# Output Formats Reference

Documentation for output formats in classroom-analyzer.

## PDF Reports

Generated using ReportLab library.

### Structure

- **Title**: Material/course name
- **Metadata**: Course, section, date
- **Description**: Original description
- **Summary**: AI-generated summary
- **Key Topics**: Bullet list of concepts
- **Analysis**: Detailed insights
- **Resources**: Table of attachments

### Styling

- Font: Helvetica
- Title: 24pt, dark blue
- Headers: 14pt, navy
- Body: 11pt, black

### Location

`outputs/reports/<name>_<timestamp>.pdf`

---

## Markdown Summaries

Plain Markdown for easy reading.

### Structure

```markdown
# [Title]

**Course**: [Name]
**Section**: [Section]
**Created**: [Date]

## Summary
[AI summary]

## Key Topics
- Topic 1
- Topic 2

## Analysis
[Detailed analysis]

## Attached Resources
- **Type**: [Title](URL)

---
*Generated by Hintly*
```

### Location

`outputs/reports/<name>_<timestamp>.md`

---

## JSON Exports

Structured data for further processing.

### Course Export Structure

```json
{
  "exported_at": "ISO timestamp",
  "course": {
    "id": "string",
    "name": "string",
    "section": "string",
    "state": "ACTIVE"
  },
  "coursework": [...],
  "materials": [...],
  "announcements": [...]
}
```

### Material Structure

```json
{
  "id": "string",
  "title": "string",
  "description": "string",
  "state": "PUBLISHED",
  "attachments": [
    {
      "type": "driveFile|youtubeVideo|link|form",
      "title": "string",
      "url": "string"
    }
  ]
}
```

### Location

`outputs/exports/<name>_<timestamp>.json`
